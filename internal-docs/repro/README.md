# Reproduction Scripts

[← Overview](../README.md) · [Value assessment](../00-value-assessment.md) · [Roadmap](../roadmap-and-recommendations.md) · [Findings](../findings/verified-findings-register.md)

These are the synthetic reproductions behind the folder's headline numbers. They were copied out of the review session's scratchpad, which is temporary, so that the numbers can be re-run. Each script was read before it was copied, then re-run on 2026-10-12 against `d13c215` with the repository's `.venv` (Python 3.10.11). The "Re-run result" column shows what that re-run printed.

**Safety properties:**

- **Synthetic only.** Inputs use placeholder accounts (`123456789012`, `111122223333`, `999999999999`, `000000000000`) and invented names. No script reads `reports/`, `tmp` or `enum.sh`.
- **Offline.** Every Python script that imports `app.*` or `boto3` starts with an offline guard: fake credentials, `/dev/null` config files, IMDS disabled, and a dead local proxy, so an accidental AWS call fails locally. The AWS-facing scripts also answer every request in-process (botocore `Stubber`, a `before-send` hook, or mocks).
- **No exploit payloads.** The dashboard XSS harnesses for [F-008](../findings/verified-findings-register.md#f-008) and [F-041](../findings/verified-findings-register.md#f-041) are deliberately **not** included. Their test strings belong in the roadmap's R-05 regression fixture, not in this folder.
- **Writes only to temporary directories**, except `def_mkreport.py`, which writes where you point it. It refuses to overwrite any directory it did not create.

**How to run:** from the repository root, `.venv/bin/python -I -B internal-docs/repro/<script>.py`, or `node internal-docs/repro/<script>.js` (Node 20) for the dashboard scripts. `-B` stops Python writing `__pycache__` files into `app/`.
